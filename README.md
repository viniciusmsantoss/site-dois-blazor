## 🚀 Exercícios Desenvolvidos

1. **Conversor de Temperatura (`/conversor`):** Converte temperatura de Celsius para Fahrenheit utilizando `@bind` e `@rendermode InteractiveServer`.
2. **Calculadora de Média (`/media`):** Recebe duas notas, calcula a média aritmética e exibe status de Aprovado (>= 7.0) ou Reprovado com validação condicional.
3. **Sorteador de Números (`/sorteio`):** Sorteia números inteiros aleatórios de 1 a 100 utilizando a classe `System.Random`.
4. **Navegação (`NavMenu.razor`):** Configuração de rotas de acesso lateral no menu com o componente `<NavLink>`.
